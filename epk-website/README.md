# Ishan EPK Website

Next.js app for the Ishan electronic press kit.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

- `npm run dev` starts the local development server.
- `npm run lint` checks the app with the current Next lint config.
- `npm run build` creates the production build.
- `npm run start` runs the production server after a build.

## Maintenance Notes

Use Node 20 for local work and Vercel deploys. The existing UI is built on the deprecated NextUI v1 beta API, so a future move to HeroUI should be treated as a small redesign rather than a drop-in package update.
